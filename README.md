# Astro Hello World

A small Astro site configured for GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

Build the production site with `npm run build`.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` deploys every push to `main`.
In the repository settings, set **Pages** to **GitHub Actions** as the source.

The site will be available at:

`https://nativeanish.github.io/blog/`
